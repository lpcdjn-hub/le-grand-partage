Le Grand Partage

Donner · Partager · Recommencer

L'application gratuite pour donner une seconde vie aux objets et partager près de chez soi.

📱 Android

  1. Ouvrez cette page dans Chrome.
  2. Appuyez sur le bouton « Installer l'application » s'il apparaît.
  3. Sinon, ouvrez le menu ⋮ de Chrome puis choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».
  4. Confirmez : l'icône apparaîtra sur votre téléphone.

🍎 iPhone / iPad

  1. Ouvrez le site dans Safari.
  2. Appuyez sur le bouton Partager.
  3. Choisissez « Sur l'écran d'accueil », puis Ajouter.
