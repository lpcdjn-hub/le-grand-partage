# Le Grand Partage

Site de partage et de dons d'objets.

## Déploiement
Le workflow GitHub Actions publie automatiquement le contenu du dépôt sur GitHub Pages à chaque mise à jour de `main`.

URL attendue : https://lpcdjn-hub.github.io/le-grand-partage/

## État actuel
Première version front-end : recherche, filtres et dépôt local d'annonces. Les annonces restent enregistrées dans le navigateur utilisé. Une base de données et une authentification partagées seront nécessaires pour la mise en relation réelle entre membres.
