# Security Policy

## Le Grand Partage — Security

Le Grand Partage takes the security and privacy of its users seriously.

### Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through GitHub's Private Vulnerability Reporting feature:

https://github.com/lpcdjn-hub/le-grand-partage/security/advisories/new

Please do not publicly disclose security vulnerabilities before they have been investigated and addressed.

When reporting a vulnerability, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any screenshots or supporting information.

### Security Updates

We regularly monitor dependencies, review security alerts, and apply security updates when necessary.

### Scope

This policy applies to the Le Grand Partage application and its associated repository.

Thank you for helping protect our community.
